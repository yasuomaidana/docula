# docula-composer

Multi-shot document reconstruction (several photos of one document into one page) and single-shot multi-document instance segmentation (one photo of several documents into several pages).

## Key types

`DocumentReconstructor`, `ReconstructionConfig`, `StitchMode`, `RegistrationMethod`, `MultiDocumentSegmenter`, `SegmentationConfig`
